## English

### About
A coursework project written in C++ using object-oriented programming.
Its goal is to design a class system that supports the day-to-day operation of a theater.

### Tech
- C++
- Object-oriented design (classes, encapsulation, inheritance)

### Getting started
Open `Kursovaya.sln` in Visual Studio, then build and run.
